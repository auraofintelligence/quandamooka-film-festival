Markdown Builders

Make useful `.md` files before the story gets messy.

These forms autosave in your browser, generate Markdown in a preview area, and let you copy or download the result. They are planning tools, not submission forms.

Common boundary included in every builder.

Each builder asks for title, creator, date, project stage, public/private boundary, cultural review need, permissions, source links, and next action. That means every `.md` file carries the human review context with it.
